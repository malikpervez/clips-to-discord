MOMENTS TO DISCORD

1. Keep every file from this ZIP together in one folder.
2. Run MomentsToDiscord.exe.
3. Choose your SteelSeries GG Moments folder.
4. Paste your Discord webhook URL.
5. Test the webhook, then save.

The app stays in the Windows notification area. It watches for clips only while
Discord is open. After a successful upload, the original clip moves into the
"uploaded" folder inside your Moments directory.

Keep your webhook URL private. If it is exposed, rotate or delete it in Discord.

This app is not affiliated with SteelSeries or Discord.
